# 标准风格图示例

《三国守御录》的五张标准风格图，内容各不相同、画风完全一致。出图时放进「参考图」节点，让新图的线条、上色和五官画法向它们看齐。

| 文件 | 内容 | 给谁当参考 |
|---|---|---|
| `warrior.png` | 无名的年轻武将，空手 | 武将、士兵 |
| `lady.png` | 无名的年轻女子，空手 | 女性角色 |
| `elder.png` | 无名的年长文官，空手 | 长须、年长的角色 |
| `soldier.png` | 普通士兵，空手 | 士兵 |
| `granary.png` | 小粮仓 | 建筑和道具 |

- 它们由 `../briefs/demo.yaml` 里的五条描述加 `../style_cards/sanguo_chibi.yaml` 出图得到，这里放的是缩到 512 像素的版本。
- 人物都不拿兵器：参考图里最显眼的东西容易被照搬到新图上，所以标准图只示范画风，不带特定道具。
- 用法：在「参考图」节点的 `paths` 里一行写一个，例如 `@repo/examples/refs/warrior.png`；或者把图片直接拖到节点上。
- 这些图是《三国守御录》项目的美术素材，随仓库提供只作示例和测试用。
