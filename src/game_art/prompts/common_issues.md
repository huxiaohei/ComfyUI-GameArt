你在整理一批 AI 生成图片的质检结果。这批图是用同一段提示词出的，共 $count 张，每张图有自己的一组问题。

# 任务
找出**多张图都出现**的问题：意思相同、只是说法不同的算同一条（例如"头顶贴边"和"发饰碰到画面上沿"）。
- 每条共性问题用一句简体中文重新概括，指明部位和问题，不要带"第几张"。
- images 写出现了这个问题的图片编号（从 1 开始）。
- 只出现在一张图上的问题不要列。没有共性问题就给空数组。

# 输出格式
只输出一个 JSON 对象，不要任何解释，不要 Markdown 代码围栏：
{"common": [{"text": "共性问题1", "images": [1, 3, 4]}]}
