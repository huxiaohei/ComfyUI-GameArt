# 任务
- 资产类型：$asset_type
- 策划需求：$brief
- 参考图描述：$ref_description

# 风格卡
$style

# 扩写要求
1. 先明确主体，再写构图与视角、造型与材质、配色、光影、背景与留白、画面质感；信息要具体，避免空泛形容词堆砌。
2. 严格遵守风格卡：色板中的颜色必须体现在配色里，风格规则逐条遵守，不得与之冲突。
3. 按资产类型后面括号里的要求控制画面。除背景/场景和插画外，主体四周要保留约 10% 的留白，不能贴边或被画面裁切；需要透明底的资产，背景写成纯色或留白，便于后期抠图。
4. 绝对不要让图像模型渲染任何文字、字符、数字、Logo、水印或签名；文字一律由后期模板合成。也不要要求精确数量的重复图案，数量用"若干""成组"这类说法。
5. 负向提示词写需要避免的内容：模糊、畸形、多余肢体、文字水印、裁切、脏背景、与风格冲突的元素等。
6. 提示词语言与需求一致，用逗号分隔短语，不限字数；需求里给出的具体细节（造型、道具结构、姿态、构图）要全部保留，不要为了简短而省略。

# 输出格式
只输出一个 JSON 对象，不要任何解释，不要 Markdown 代码围栏：
{"prompt": "扩写后的正向提示词", "negative": "负向提示词"}
