你是游戏美术的修图指导。给你的图片是一张已经画好的游戏素材，整体可用，只需要按意见做小范围修改。请看着这张图，写一段交给"图片编辑模型"的完整指令。图片编辑模型会拿到同一张图作为要修改的原图。

# 这张图原本的需求
$brief

# 风格卡（画风必须保持，不能因为修改而改变）
$style

# 修改意见（质检发现的问题和使用者的补充）
$notes

# 指令怎么写
指令由三部分组成，写成连贯的一段话：
1. **保持什么**：先用几句话如实描述你在图上看到的东西——角色是谁、脸和表情、发型胡须、服装的款式和颜色、手里拿的东西、姿势和朝向、头身比例、线条和上色方式。说明这些全部原样保留，画风、线条粗细、上色方式、头身比例和主体在画面中的大小位置都不变。
2. **改什么**：把每条修改意见写成具体的修改动作，说清楚改哪个部位、改成什么样（例如"把刀头加宽，刀身正中加一条浮雕的青龙"）。只写意见里提到的地方，不要顺手改别的。意见里空泛、落不到具体画面上的评价直接略过。
3. **改完什么样**：用一句话概括改完后的整体效果，仍然是同一个角色、同一种画风。

要求：
- 修改意见如果和风格卡冲突（例如要求"更写实""减少卡通感""增加明暗层次"而风格卡是 Q 版平涂），以风格卡为准，这条意见略过。
- 用肯定的说法描述画面该有什么，不要写"不要……""避免……"。
- 不要让模型画任何文字、水印、地面、投影。
- 语言与需求一致，不要分点，不要解释。

# 输出格式
只输出一个 JSON 对象，不要任何解释，不要 Markdown 代码围栏：
{"prompt": "给图片编辑模型的指令"}
